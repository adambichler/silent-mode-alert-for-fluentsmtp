# Contributing

Thank you for helping improve Silent mode alert for FluentSMTP.

## Before submitting a change

1. Confirm the change works with WordPress 6.5 or newer and the current supported FluentSMTP release.
2. Run the PHP syntax checks from the project README.
3. Test the affected workflow with FluentSMTP active, including the unavailable-dependency path when relevant.
4. Keep user-facing strings translatable and preserve the existing text domain.
5. Do not include generated ZIP files, credentials, or macOS metadata in commits.

Bug reports and feature requests can be opened as GitHub issues. User support belongs in the WordPress.org support forum.
